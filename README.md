# 정보 학습 사이트 (5단계: 파이썬 100문제 전체 채우기)

## 이번 업데이트로 추가된 것
- 파이썬 문제 9번~100번(92개) 추가 → 이제 총 100문제 완성
  - 1회차(1~40번): 조건문 + 기초 반복문 (if/for/while 기본)
  - 2회차(41~70번): 반복문 + 중첩 반복문 (리스트 활용 포함)
  - 3회차(71~100번): 함수 + 문자열 (조건문·반복문·리스트까지 종합)
- 각 문제의 정답은 실제로 파이썬 코드를 돌려서 나온 출력값을 기준으로 해시를 계산했습니다 (오채점 방지)

## 적용 순서

### 1. Supabase에 문제 92개 추가
1. supabase.com 대시보드 → SQL Editor → New query
2. `supabase/migration_005.sql` 내용을 전체 복사해서 붙여넣고 **Run**
3. "Success" 메시지 확인

### 2. 코드 덮어쓰기 + GitHub에 올리기
```
git add .
git commit -m "파이썬 문제 9~100번 92개 추가"
git push
```
(이번엔 코드 변경은 없고 `supabase/migration_005.sql` 파일과 이 README만 추가/수정됐어요. 그래도 기록을 위해 똑같이 git에 올려주세요.)

### 3. 확인
1. 학생 계정으로 로그인 → 2학년 → 파이썬 문제풀이 → 회차 선택 화면에서 이제 1/2/3회차 모두 "40문제", "30문제", "30문제"로 표시되는지 확인
2. 2회차 또는 3회차 "시작하기"를 눌러서 이제 "이 회차에 아직 등록된 문제가 없습니다" 메시지 없이 문제 목록이 뜨는지 확인
3. 문제 몇 개를 직접 풀어보면서 정답 처리가 정상적으로 되는지 확인 (문제 설명에 나온 대로 코드를 작성하면 정답 처리되어야 함)
