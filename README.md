# 정보 학습 사이트 (7단계: 파이썬 문제해결 프로젝트)

## 이번 업데이트로 추가된 것
- **"파이썬 문제해결 프로젝트"** 화면을 실제로 만들었어요 (이전엔 "준비 중" 알림만 떴던 화면)
- 자동채점이 아니라 **보고서형 프로젝트** 제출 방식이에요. 공유해주신 보고서 양식대로 구성했습니다:
  1. 프로젝트 제목
  2. 목적 및 주제 선정
  3. 알고리즘 설계
  4. 코드 작성 (직접 실행해보고 결과 확인 가능 — 기존 파이썬 문제풀이와 같은 방식)
  5. 실행 결과 + 설명
  6. 후기 및 개선 방향
  7. AI 활용 관련 안내 (사용 여부/방식을 학생이 직접 기재)
  8. 자기 점검표 (체크리스트)
- 학생은 **임시저장**을 여러 번 하다가 준비되면 **제출하기**로 확정할 수 있어요 (제출 후에도 다시 수정·재제출 가능)
- **교사 대시보드에 "🛠️ 프로젝트 제출 현황" 표 추가**: 학생별 제출 상태(시작 안 함/작성 중/제출 완료)를 확인하고, "보고서 보기"로 전체 내용을 읽어볼 수 있어요

## 적용 순서

### 1. Supabase에 프로젝트 보고서 표 추가
1. supabase.com 대시보드 → SQL Editor → New query
2. `supabase/migration_006.sql` 내용을 전체 복사해서 붙여넣고 **Run**

### 2. 코드 덮어쓰기 + GitHub에 올리기
```
git add .
git commit -m "파이썬 문제해결 프로젝트 기능 추가"
git push
```

### 3. 확인
1. 학생 계정으로 로그인 → 2학년 → **"파이썬 문제해결 프로젝트"** 클릭 → 보고서 작성 화면이 뜨는지 확인
2. 코드 작성란에 간단한 코드(예: `print("테스트")`) 넣고 "코드 실행하기" → 실행 결과가 뜨는지 확인
3. 몇 개 항목 채우고 "임시저장" → 새로고침해도 내용이 남아있는지 확인
4. "제출하기" → "제출 완료" 표시가 뜨는지 확인
5. **교사 계정으로 로그인** → 대시보드에서 "🛠️ 프로젝트 제출 현황" 표에 방금 그 학생이 "제출 완료"로 뜨는지 확인 → "보고서 보기"로 내용이 잘 보이는지 확인
