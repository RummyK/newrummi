# 정보 학습 사이트 (10단계: 프로젝트 보고서 2종 선택 - 탐구 보고서 / Padlet업로드 보고서)

## 이번 업데이트로 추가된 것
"파이썬 문제해결 프로젝트"를 누르면 이제 **보고서 종류를 먼저 선택**하도록 바뀌었어요.

- **📘 탐구 보고서**: 지금까지 쓰던 보고서 그대로예요. 내용도, 제출 현황도 전혀 바뀐 게 없어요.
- **📌 Padlet업로드 보고서**: 새로 만든 보고서예요. 보내주신 슬라이드 양식을 그대로 따라서 만들었어요.
  - 과목 선택(정보/수학/과학), 프로젝트 제목
  - 01 프로젝트 개요 (목적 / 주제 선정 이유)
  - 02 알고리즘 설계 (입력받기→조건판단→처리수행→결과저장→출력 5단계 + 조건문/반복문/함수 핵심 개념 표)
  - 03 파이썬 코드 (직접 실행해보는 기능 포함) + 코드 설명
  - 04 실행 결과 & 분석 (실행 결과 / 결과 분석 / 오류 및 개선)
  - 05 프로젝트 후기 (배운 점 / 어려웠던 점 / 발전 방향)
  - AI 유의사항 작성란
  - 자기 점검표 (파이썬 문제풀이 50점 / 문제해결 과정 기록 30점 / 프로젝트 보고서 20점, 그룹별 체크리스트)
  - 제출하면 지난 업데이트와 같은 "📋 Padlet 게시용 내용 복사하기" 버튼이 나타나요.
- **교사 대시보드**에 "📌 Padlet업로드 보고서 제출 현황" 표가 새로 생겼어요. 학번·이름·과목·제목·제출 상태를 한눈에 보고, "보고서 보기"를 누르면 학생이 작성한 내용을 전부(체크리스트 포함) 확인하고 PDF로도 저장할 수 있어요.
- 두 보고서는 완전히 분리된 별도의 표(테이블)로 저장돼요. 탐구 보고서 데이터나 기존 기능은 전혀 건드리지 않았습니다.

## 적용 순서

### 1. Supabase에서 새 SQL 실행
Supabase 대시보드 → **SQL Editor** → 아래 파일 내용을 붙여넣고 실행(Run)하세요.

```
supabase/migration_008.sql
```

(이 SQL은 새로운 `padlet_reports` 표를 만들기만 해요. 기존 표는 전혀 건드리지 않습니다.)

### 2. 코드 덮어쓰기 + GitHub에 올리기
1. 다운로드한 압축파일 (`python-site-v13.zip`)의 내용을 `python-site` 폴더에 그대로 덮어써주세요.
2. Git Bash에서 `python-site` 폴더로 이동한 뒤, 아래 세 줄을 **한 줄씩** 순서대로 입력하고 Enter:
```
git add .
git commit -m "프로젝트 보고서 2종 선택 기능 추가 (탐구 보고서 / Padlet업로드 보고서)"
git push
```
Vercel이 자동으로 재배포해줘요 (1~2분 정도 걸려요).

### 3. 확인
1. 학생 계정으로 로그인 → 2학년 → "🛠️ 파이썬 문제해결 프로젝트" 클릭
2. "📘 탐구 보고서"를 눌러서 예전과 똑같이 작동하는지 확인
3. 뒤로 가서 "📌 Padlet업로드 보고서"를 눌러 새 양식이 잘 뜨는지 확인 (과목 선택, 5단계 알고리즘, 핵심 개념 표, 코드 실행, 자기 점검표 등)
4. 임시저장 → 다시 들어가서 내용이 남아있는지 확인 → 제출하기
5. "📋 Padlet 게시용 내용 복사하기" 버튼으로 복사 확인
6. 교사 계정으로 로그인 → 대시보드에서 "📌 Padlet업로드 보고서 제출 현황" 표에 방금 제출한 학생이 보이는지, "보고서 보기"로 내용이 잘 나오는지, PDF 저장도 되는지 확인
