# 정보 학습 사이트 (3단계: 파이썬 문제풀이)

## 이번 업데이트로 추가된 것
- 로그인 후 학년 선택 화면 (1/2/3학년 — 지금은 2학년만 동작, 나머지는 "준비 중")
- 2학년 선택 시 "파이썬 문제풀이" / "파이썬 문제해결 프로젝트" 선택 화면 (프로젝트는 아직 준비 중)
- 파이썬 문제풀이: 브라우저에서 직접 파이썬 코드를 작성·실행(Pyodide)하고 자동 채점
- 채점은 반드시 **서버**에서 합니다 — 정답 자체는 학생 화면에 절대 내려가지 않고, 학생이 실행한 결과의 SHA-256 해시만 서버가 비교합니다.
- 무한 루프 코드를 실행해도 8초 후 자동으로 실행을 강제 종료하도록 안전장치를 넣었습니다.
- 샘플 문제 8개 포함 (나중에 문제를 추가하려면 `supabase/migration_003.sql`을 참고해서 같은 방식으로 넣으면 됩니다.)

## 적용 순서

### 1. Supabase에 샘플 문제 넣기
1. supabase.com 대시보드 → SQL Editor → New query
2. `supabase/migration_003.sql` 내용을 전체 복사해서 붙여넣고 **Run**
   (이미 `schema.sql`, `migration_002.sql`을 실행하신 상태여야 합니다.)

### 2. 코드 덮어쓰기 + GitHub에 올리기
이번 압축 파일의 내용을 기존 `python-site` 폴더에 덮어쓴 뒤:
```
git add .
git commit -m "파이썬 문제풀이 자동채점 기능 추가"
git push
```

### 3. 확인
1. 학생 계정으로 로그인 → 학년 선택 화면이 뜨는지 확인
2. "2학년" 선택 → "파이썬 문제풀이" / "파이썬 문제해결 프로젝트" 두 버튼이 보이는지 확인
3. "파이썬 문제풀이" 클릭 → 문제 목록(8개)이 보이는지 확인
4. 아무 문제나 클릭해서 들어간 뒤, 정답에 해당하는 코드를 작성하고 "실행 및 채점" 클릭
   - 예: 1번 문제("Hello, Python!" 출력)는 `print("Hello, Python!")` 을 입력하고 실행하면 "정답입니다!"가 떠야 합니다.
   - 처음 실행할 때는 파이썬 환경(Pyodide)을 내려받느라 몇 초 정도 걸릴 수 있습니다 (이후로는 빨라집니다).
5. 일부러 `while True: pass` 같은 무한 루프 코드를 넣고 실행해서, 8초 후 "실행 시간이 너무 깁니다" 메시지가 뜨고 화면이 멈추지 않는지 확인해주세요.

문제 생기면 화면을 캡처해서 보여주세요.
