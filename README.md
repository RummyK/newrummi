# 정보 학습 사이트 (4단계: 회차별 타이머)

## 이번 업데이트로 추가된 것
- 100문제를 **40 / 30 / 30**으로 나눈 3개 회차 (문제 번호 1~40 = 1회차, 41~70 = 2회차, 71~100 = 3회차)
- 회차마다 제한시간 **50분**
- 학생이 "시작하기" 버튼을 누른 순간부터 타이머가 서버에 기록되고, 화면에 카운트다운으로 보임
- 새로고침하거나 다른 문제로 이동해도 타이머는 계속 흐름 (서버에 기록된 시각 기준이라 초기화 안 됨)
- 시간이 끝나면 서버가 채점 자체를 거부함 (학생이 컴퓨터 시간을 조작해도 소용없음)
- 현재는 샘플 문제 8개만 있어서 전부 1회차에 들어있습니다. 2·3회차는 문제를 채워 넣기 전까지 "문제가 없습니다"로 표시됩니다.

## 적용 순서

### 1. Supabase에 회차 기록용 표 추가
1. supabase.com 대시보드 → SQL Editor → New query
2. `supabase/migration_004.sql` 내용을 전체 복사해서 붙여넣고 **Run**

### 2. 코드 덮어쓰기 + GitHub에 올리기
```
git add .
git commit -m "회차별 50분 타이머 기능 추가"
git push
```

### 3. 확인
1. 학생 계정 로그인 → 2학년 → 파이썬 문제풀이 → **회차 선택 화면**이 뜨는지 확인 (1/2/3회차 카드, 각각 "50분" 표시)
2. 1회차 "시작하기" 클릭 → 카운트다운(49:59, 49:58...)이 시작되는지 확인
3. 문제 하나를 풀어보고, 문제 화면 상단에도 같은 카운트다운이 보이는지 확인
4. 새로고침해도 타이머가 리셋되지 않고 이어지는지 확인
5. (선택) 시간이 다 되면 "실행 및 채점" 버튼이 비활성화되고 제출이 막히는지 확인 — 급하게 테스트하려면 Supabase Table Editor에서 `round_attempts` 표의 `ends_at` 값을 몇 분 전 시각으로 직접 수정해서 테스트할 수 있습니다.
