# 정보 학습 사이트 (2단계: 학생 계정 관리)

## 이번 업데이트로 추가된 것
- 교사 대시보드에서 학생을 여러 명 한 번에 등록 (엑셀 붙여넣기 방식)
- 신규 학생은 공통 초기 비밀번호로 시작하고, 첫 로그인 시 반드시 새 비밀번호로 변경
- 학생 목록 확인, 개별 학생 비밀번호 재설정(분실 시)
- 로그인 5회 연속 실패 시 10분간 잠금 (무차별 대입 공격 방어)
- 로그아웃 버튼

## 적용 순서

### 1. Supabase에 새 컬럼/표 추가
1. supabase.com 대시보드 → 프로젝트 → **SQL Editor** → New query
2. `supabase/migration_002.sql` 파일 내용을 전체 복사해서 붙여넣고 **Run**
   (이미 `schema.sql`을 실행한 상태여야 합니다. 처음 설치라면 `schema.sql`을 먼저 실행하세요.)

### 2. 코드 받기
이 폴더 전체를 기존 `python-site` 폴더 내용과 **덮어쓰기** 하세요. (기존 `.env.local` 파일이 있다면 그건 그대로 두고, 이 zip의 다른 파일들로 덮어씁니다.)

### 3. GitHub에 다시 올리기
터미널에서 python-site 폴더로 이동한 뒤:
```
git add .
git commit -m "학생 계정 관리 기능 추가"
git push
```
push하면 Vercel이 자동으로 재배포합니다.

### 4. 확인
1. `/teacher/dashboard`에서 로그인 후, 학생 정보를 붙여넣기 형식(`학번,이름,학년,반`)으로 입력하고 초기 비밀번호를 정해서 "학생 등록"을 눌러보세요.
2. 시크릿 창에서 방금 등록한 학번+이름+초기 비밀번호로 `/login`에서 로그인해보세요.
3. 첫 로그인이므로 자동으로 비밀번호 변경 화면으로 이동해야 합니다. 새 비밀번호로 바꾼 뒤 `/dashboard`로 넘어가는지 확인하세요.
4. 다시 로그아웃 후, 이번엔 새로 바꾼 비밀번호로 로그인해서 바로 `/dashboard`로 들어가는지 확인하세요 (비밀번호 변경 화면이 다시 뜨면 안 됩니다).

문제 생기면 화면을 캡처해서 보여주세요.
