# 정보 학습 사이트 (6단계: 교사용 진행 현황 + 회차 이동 개선)

## 이번 업데이트로 추가된 것
- **교사 대시보드에 "학생 진행 현황" 표 추가**: 학생별로 전체 100문제 중 정답/오답 개수를 한눈에 확인
- 학생별 **"상세보기"** 클릭 시, 회차별로 어떤 문제를 맞았는지/틀렸는지/아직 안 풀었는지 전체 목록으로 확인 가능 (필터로 정답만/오답만/미시도만 보기도 가능)
- 학생이 문제를 채점한 직후, 바로 **"◯회차 목록으로 돌아가기"** 버튼이 떠서 같은 회차의 다른 문제로 빠르게 이동 가능 (화면 상단 버튼도 회차 선택 화면이 아니라 해당 회차 목록으로 바로 이동하도록 변경)
- (지난 업데이트, 참고) 홈 화면에 별이 반짝이는 배너 + "남목고등학교 정보 수행평가 사이트 / 김아름T" 문구 추가, 전체적인 디자인 개선

## 적용 순서

### 1. 코드 덮어쓰기 + GitHub에 올리기
이번엔 DB 변경(SQL)은 없고 코드만 바뀌었어요.
```
git add .
git commit -m "교사용 학생 진행 현황 + 회차 이동 개선"
git push
```

### 2. 재배포 확인
Vercel이 자동으로 재배포합니다. "Ready" 될 때까지 1~2분 기다려주세요.

### 3. 확인
1. **교사 계정으로 로그인** → 대시보드 맨 위에 "📊 학생 진행 현황" 표가 뜨는지 확인 (학생별 정답/오답 개수)
2. 학생 하나 골라서 **"상세보기"** 클릭 → 회차별로 문제 목록과 정답/오답/미시도 상태가 뜨는지 확인
3. **학생 계정으로 로그인** → 문제 하나 풀고 채점 → 결과 메시지 아래에 "◯회차 목록으로 돌아가기" 버튼이 뜨는지, 눌렀을 때 해당 회차의 문제 목록으로 바로 이동하는지 확인
4. 화면이 예전 그대로로 보이면 브라우저에서 **Ctrl + Shift + R**(강력 새로고침)을 한 번 해보세요 (캐시된 이전 화면일 수 있어요)
